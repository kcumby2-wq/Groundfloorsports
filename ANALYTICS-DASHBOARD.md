# Seller Upload Analytics Dashboard (Planned)

## Features
- Total uploads, published, pending, failed
- Storage usage and quota
- Upload success/failure rates
- Moderation actions (approved/taken down)
- Views, downloads, sales (future)
- Time series charts (uploads per day/week)
- Export to CSV

## API Endpoints
- `/api/seller/uploads/analytics` (planned)
- `/api/seller/uploads/storage-usage`
- `/api/seller/uploads/moderate`

## UI
- Table of uploads with status
- KPIs: total, published, quota
- Charts: uploads over time, moderation actions
