Company handoff

Use Athletes for daily ops, CSV Builder for combine and clinic intake, and Settings for setup, backups, and recovery. The admin is designed so a non-developer can run the common flows without touching code.

Role Can do Should not do
Viewer Review dashboards and previews only Edit athletes, export backups, clear data
Operator Add and edit athletes, run CSV Builder, process daily ops Clear all data or bypass approvals
Manager Bulk updates, snapshot restore, export backups, approval flows Rotate secrets or make environment changes casually
Super Admin Everything above plus destructive recovery actions Use high-risk actions without a backup first
Daily flow
  1. Open the dashboard and confirm Supabase is connected.
  2. Use Athletes for roster edits and bulk status/package updates.
  3. Open CSV Builder when collecting combine or clinic rows.
  4. Export CSV and save a backup before any bulk or destructive action.
Recovery path
  • Reconnect Supabase from the top-level button if the project URL or key changes.
  • Restore the latest snapshot if local draft work is lost.
  • Use the backup export before clearing or importing large batches.
  • Escalate to a Super Admin for secret rotation or data recovery.

Backups & exports

Keep a recent export before large edits, and use snapshots for local recovery. The latest export, backup, and reconnect times are tracked in the dashboard status strip.

Restore notes
  • Use the latest snapshot first when you need to recover local data fast.
  • Use the export history to confirm the last successful CSV or backup file.
  • Restore athletes from a backup only after you export the current state.
Backup routine
  1. Export a CSV before bulk cleanup or imports.
  2. Create a snapshot after a major import or recovery.
  3. Record the reconnect time whenever Supabase credentials change.
  4. Print or archive the settings page when handing off to a new team.
