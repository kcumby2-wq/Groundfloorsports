Quick Start Checklist

Use this before and during an event so your CSV exports are clean and ready for Prospect Edge import.

  1. Request an admin access call and complete admin purchase.
  2. After onboarding, open CSV Builder and set event series, type, date, and location.
  3. Import existing rows or add athlete rows manually.
  4. Confirm each row includes first name, last name, position, class year, and school/team.
  5. Choose Notes behavior and context format for transcript detail.
  6. Export CSV or Export By Date, then upload into Prospect Edge.
