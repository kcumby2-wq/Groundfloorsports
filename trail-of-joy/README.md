# Trail of Joy — Agency SOPs

This folder is the durable memory of the Trail of Joy agent system. Bring these files into every new session so agents start where the last one left off.

## Files
- `OPERATING-CHARTER.md` — standing rules, 95% target, permanent 5% human gates
- `AGENT-SOP-deploy-interface-backend.md` — DEPLOYER v1.1
- `AGENT-SOP-campaign-deploy.md` — CAMPAIGNER v1.0 (non-GHL campaigns)
- `AGENT-SOP-qa-verification.md` — QA v1.0
- `LEARNING-LOOP.md` — append-only record across all projects

## How to use in a new session
1. Upload or paste the relevant SOP(s) at the start of the conversation
2. Agent reads the loop ledger and picks up where the last run ended
3. After the run, append a new loop entry and propose any SOP version bump
