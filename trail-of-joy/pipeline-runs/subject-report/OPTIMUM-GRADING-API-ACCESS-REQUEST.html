02 What We Are Building
We are developing an integrated digital infrastructure that uses Prospect Edge as the evaluation engine across multiple platforms and client brands. The API access we are requesting enables three core product functions:
Use Case 1
Athlete Evaluation Pipeline
Trainers submit athlete film. Evaluations are completed in Prospect Edge. Transcripts are automatically pushed to the athlete's profile on the trainer's website and to the family via automated delivery — without any manual export or copy-paste step.
Use Case 2
Coach-Facing Prospect Database
Athlete profiles and evaluation scores from Prospect Edge populate a subscription-gated coach portal. College coaches pay to access early, ongoing visibility into a trainer's full athlete roster — filtered by position, class year, and evaluation grade.
Use Case 3
Season-Long Progress Tracking
Athletes are evaluated multiple times per season. Each evaluation updates their profile automatically. Coaches and families see a live, timestamped development arc — not just a single snapshot — showing measurable improvement over time.
Use Case 4
Multi-Brand Deployment
TOJ manages multiple client brands. Each client (trainer, program, or management group) needs its own Prospect Edge integration deployed through a consistent API layer — not manual platform-by-platform setup for each new client.
