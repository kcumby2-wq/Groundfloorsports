# Event Company Onboarding Script

## Goal
Convert event organizers from access request to approved, paid, and provisioned operations.

## 60-second opener
Hi [Organizer Name], this is [Your Name] with Subjectreport. I want to confirm your event setup, show how CSV Builder supports your intake workflow, and map the exact steps from approval to live event usage.

## Qualification checklist
- Event name, date, and location confirmed.
- Primary operator contact and backup contact confirmed.
- Expected athlete volume and export format requirements confirmed.
- Billing owner and purchase path confirmed.

## Access flow
1. Request received and moved to reviewing.
2. Approval call completed.
3. Admin purchase confirmed.
4. Access marked approved/provisioned.
5. Operator runs CSV Builder with event-specific setup.

## Risk checks
- Ensure popup blocker instructions are clear before scheduler handoff.
- Verify export template match before event day.
- Assign one owner for day-of-event CSV quality checks.

## Close
After purchase confirmation, we immediately approve access, complete onboarding, and run a short CSV readiness check before your event.

## Internal checklist after call
- Update request queue status and sync to Supabase.
- Mark onboarding checklist items completed.
- Capture event metadata in notes and activity log.
- Confirm support channel for live event day.
